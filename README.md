# vibe-translator

Переводит фразы на два регистра:
- корпоративный (по мотивам публикации Ильяхова на Sponsr);
- шизотерический (по мотивам концепции «слово как вибрация»).

## Запуск
python3 translator.py "в 2020 году в нефтегазовой компании миллионы тратились на коучинг"

Или интерактивно:
python3 translator.py

## Ограничения
- Это rule-based прототип: замены по словарю, без понимания контекста.
- Удаление частицы «не» — грубое упрощение; корректная обработка отрицаний требует LLM.
- Сарказм и мат не переводятся «в ноль»: они либо исчезают, либо маскируются.
- Для продакшена: заменить apply_rules на вызов LLM с few-shot промптами
  и валидацией выхода.

##Пример
python3 translator.py "я устал и не хочу ничего делать"

=== Корпоративный ===
На текущем этапе ощущаю значительное выгорание и потерю мотивации — необходим перезагрузочный трек для восстановления ресурса.

=== Шизотерический ===
Я ощущаю слив энергии и выбираю сейчас состояние восстановления ресурса.
